# 熵系数线性衰减功能说明

## 🎯 功能概述

熵系数衰减是一个关键的训练技巧，用于平衡强化学习过程中的探索与利用。通过在训练过程中逐步降低熵系数，可以实现：
- **训练初期**：高探索性，帮助智能体发现多样化的行为策略
- **训练后期**：低探索性，稳定策略收敛到最优解

## ⚙️ 参数配置

### 新增命令行参数

```bash
--entropy_coef_start 0.015      # 初始熵系数 (默认: 0.015)
--entropy_coef_end 0.005        # 最终熵系数 (默认: 0.005)  
--entropy_decay_end_ratio 0.8   # 衰减完成的训练进度比例 (默认: 0.8)
```

### 衰减逻辑

```python
# 计算训练进度
progress = current_step / total_timesteps

if progress <= entropy_decay_end_ratio:
    # 线性衰减阶段
    decay_progress = progress / entropy_decay_end_ratio
    current_entropy_coef = start + (end - start) * decay_progress
else:
    # 保持最终值
    current_entropy_coef = entropy_coef_end
```

## 📊 衰减示例

假设配置：`start=0.02, end=0.005, end_ratio=0.8, total_steps=10000`

| 训练步数 | 训练进度 | 衰减进度 | 熵系数 | 阶段 |
|----------|----------|----------|--------|------|
| 0 | 0% | 0% | 0.020 | 探索期 |
| 2000 | 20% | 25% | 0.016 | 衰减中 |

| 10000 | 100% | - | 0.005 | 稳定期 |

## 📈 监控指标

### TensorBoard指标
- **train/entropy_coef**: 实时熵系数变化曲线
- **train/entropy**: 策略熵值 (应该跟随熵系数下降)
- **train/policy_loss**: 策略损失变化
- **train/clipfrac**: 裁剪比例 (反映策略更新幅度)

### CSV日志

## 🔧 调优建议

### 1. 参数选择原则

**初始熵系数 (entropy_coef_start)**
- 太高 (>0.05): 可能导致训练不稳定
- 太低 (<0.01): 探索不足，容易陷入局部最优
- 推荐：0.015-0.03

**最终熵系数 (entropy_coef_end)**
- 太高 (>0.01): 策略可能不收敛
- 太低 (<0.001): 可能过早收敛
- 推荐：0.003-0.008

**衰减完成比例 (entropy_decay_end_ratio)**
- 太早 (<0.6): 探索期太短
- 太晚 (>0.9): 收敛期太短
- 推荐：0.7-0.85

### 2. 根据任务调整

**简单任务**：
- 较低的初始熵系数
- 较早的衰减完成时间

**复杂任务 (如MetaDrive)**：
- 较高的初始熵系数
- 较晚的衰减完成时间
- 更长的训练步数

### 3. 异常检测

**训练不稳定**：
- 降低初始熵系数
- 延后衰减完成时间

**收敛过慢**：
- 增加初始熵系数
- 提前衰减完成时间

**策略振荡**：
- 增加最终熵系数
- 使用更平缓的衰减曲线
