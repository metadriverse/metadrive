# MetaDrive PPO训练奖励配置优化指南

## 🎯 奖励配置概述

为了解决Success Rate为0的问题，我们对PPO训练的奖励配置进行了全面优化，主要目标是：
1. 鼓励智能体学会沿道路行驶
2. 增强车道保持能力
3. 平衡探索与利用
4. 提供合理的成功激励

## ⚙️ 新增的奖励配置参数

### 🏆 正向奖励 (鼓励行为)

```bash
--success_reward 25.0        # 成功到达目标奖励 (默认: 20.0)
--driving_reward 3.0         # 前进距离奖励 (默认: 2.0) 
--speed_reward 0.5           # 速度奖励 (默认: 0.3)
--use_lateral_reward         # 启用车道保持奖励 (默认: True)
```

### ⚡ 负向奖励 (惩罚行为)

```bash
--out_of_road_penalty 8.0    # 冲出道路惩罚 (默认: 8.0)
--crash_penalty 8.0          # 碰撞惩罚 (默认: 8.0)
```

## 🔧 关键优化说明

### 1. **车道保持奖励 (最重要)**
```python
"use_lateral_reward": True  # 默认False -> True
```
- **作用**: 奖励车辆保持在车道中心
- **效果**: 显著减少冲出道路的概率
- **建议**: 始终启用此选项

### 2. **前进奖励增强**
```python
"driving_reward": 2.0  # 默认1.0 -> 2.0
```
- **作用**: 鼓励车辆沿道路前进
- **效果**: 提高路径完成度
- **调节**: 1.0-3.0之间，过高可能导致鲁莽驾驶

### 3. **成功奖励提升**
```python
"success_reward": 20.0  # 默认10.0 -> 20.0
```
- **作用**: 强化到达目标的激励
- **效果**: 提高长期规划能力
- **调节**: 15.0-30.0之间，需要与其他奖励平衡

### 4. **惩罚机制优化**
```python
"out_of_road_penalty": 8.0     # 默认5.0 -> 8.0
"crash_vehicle_penalty": 8.0   # 默认5.0 -> 8.0
"crash_object_penalty": 8.0    # 默认5.0 -> 8.0
"crash_sidewalk_penalty": 2.0  # 默认0.0 -> 2.0
```
- **作用**: 增强对危险行为的抑制
- **效果**: 提高安全驾驶意识
- **调节**: 建议保持在5.0-12.0之间

## ⚠️ 调优注意事项

### 1. **奖励平衡原则**
- Success reward : Driving reward ≈ 10:1 到 15:1
- Penalty不应超过success reward的50%
- Speed reward应小于driving reward

### 2. **训练异常检测**
- 如果Value Loss急剧增长 (>100)，降低奖励幅度
- 如果Policy Loss不收敛，检查奖励设置
- 如果Episode长度不增长，增加driving reward

### 3. **超参数协调**
```bash
# 高奖励配置建议搭配：
--lr 1e-4              # 较小学习率
--entropy_coef 0.02    # 适当增加探索
--n_steps 1024         # 更长rollout
```

## 🔍 监控重点指标

### TensorBoard关键指标
1. **eval/path_completion** - 最重要！应持续增长
2. **eval/success_rate** - 目标指标，应逐步从0%提升
3. **eval/offroad_rate** - 应逐步降低
4. **train/value_loss** - 不应急剧增长
5. **env/ep_len_mean** - Episode长度应增加

### 调优建议
- path_completion < 10% → 增加driving_reward
- success_rate长期为0 → 检查success_reward设置
- value_loss > 100 → 降低所有奖励幅度
- offroad_rate > 90% → 确保use_lateral_reward=True
