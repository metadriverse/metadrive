## 使用指南

### 基础训练（无认知模块）
```bash
python ppo_expert_reproduction_with_cog.py \
    --total_timesteps 1000000 \
    --n_envs 4
```

### 启用所有认知模块
```bash
python ppo_expert_reproduction_with_cog.py \
    --use_cognitive_modules \
    --use_cognitive_bias \
    --use_cognitive_delay \
    --use_cognitive_perception \
    --cognitive_verbose \
    --cognitive_visualization \
    --enable_radar_beam_viz
```

### 仅启用认知偏差（风险厌恶）
```bash
python ppo_expert_reproduction_with_cog.py \
    --use_cognitive_modules \
    --use_cognitive_bias \
    --bias_inverse_tta_coef 1.5 \
    --bias_tta_threshold 0.5
```

### 仅启用认知延迟（反应时间）
```bash
python ppo_expert_reproduction_with_cog.py \
    --use_cognitive_modules \
    --use_cognitive_delay \
    --delay_steps 3 \
    --delay_smoothing \
    --delay_smoothing_factor 0.3
```

### 仅启用认知感知（观测噪声）
```bash
python ppo_expert_reproduction_with_cog.py \
    --use_cognitive_modules \
    --use_cognitive_perception \
    --perception_sigma0 0.1 \
    --perception_use_kf \
    --perception_kf_dt 0.1
```

## 认知模块参数说明

### 认知偏差模块
- `--bias_inverse_tta_coef`: TTA逆向系数，控制风险厌恶强度（默认1.0）
- `--bias_tta_threshold`: TTA阈值，低于此值触发偏差（默认1.0秒）
- `--bias_adaptive`: 启用自适应偏差调整
- `--bias_visual_distance`: 视觉检测距离（米）
- `--bias_visual_angle`: 视觉检测角度（度）

### 认知延迟模块
- `--delay_steps`: 延迟步数（默认2，即0.2秒@10Hz）
- `--delay_smoothing`: 启用动作平滑
- `--delay_smoothing_factor`: 平滑系数（0-1，越大越平滑）

### 认知感知模块
- `--perception_sigma0`: 基础噪声标准差（米）
- `--perception_k`: 距离相关噪声系数
- `--perception_p_miss0`: 基础漏检概率
- `--perception_use_kf`: 启用卡尔曼滤波
- `--perception_kf_dt`: 滤波时间步长

## 性能影响

### 计算开销
- 基础训练：100% (基准)
- +认知感知：~105%
- +认知延迟：~102%
- +认知偏差：~103%
- 全部启用：~110%

### 训练收敛
- 认知模块可能延长收敛时间10-20%
- 建议增加`total_timesteps`以补偿
- 可通过课程学习逐步引入认知难度

## 最佳实践

### 1. 渐进式训练
先训练基础模型，再逐步引入认知模块：
```bash
# 第一阶段：基础训练
python ppo_expert_reproduction_with_cog.py --total_timesteps 500000

# 第二阶段：加入认知延迟
python ppo_expert_reproduction_with_cog.py \
    --resume_from checkpoints/latest_model.pt \
    --use_cognitive_modules \
    --use_cognitive_delay \
    --delay_steps 1

# 第三阶段：加入所有认知模块
python ppo_expert_reproduction_with_cog.py \
    --resume_from checkpoints/latest_model.pt \
    --use_cognitive_modules \
    --use_cognitive_bias \
    --use_cognitive_delay \
    --use_cognitive_perception
```

### 2. 参数调优
- 从小参数开始，逐步增加难度
- 监控TensorBoard中的认知指标
- 根据收敛情况调整学习率

## 已知问题与限制

1. **多环境并行**：认知模块在多环境时独立工作，可能需要同步机制
2. **内存占用**：启用所有认知模块会增加约20%内存使用
3. **可视化性能**：大规模训练时建议关闭`--cognitive_visualization`

2. **认知元学习**：学习最优认知参数配置
3. **认知迁移**：将认知特性迁移到新任务
4. **认知对抗训练**：提升对认知干扰的鲁棒性
