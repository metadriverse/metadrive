# 认知偏差模块（CognitiveBiasModule）

## 模块简介

认知偏差模块是一个独立的Python模块，用于模拟人类驾驶员在面对潜在风险时的认知偏差行为。该模块基于时间到达（Time-To-Arrival, TTA）和逆时间到达（inverse_tta）值动态调整强化学习的奖励信号，模拟人类驾驶员的风险厌恶特性。

## 核心功能

### 1. 风险厌恶建模
- **基于inverse_tta的偏差**：当环境中的inverse_tta值超过设定阈值时，模块会对奖励信号施加负偏差（惩罚）
- **动态强度调整**：偏差强度与inverse_tta值成正比，风险越高，惩罚越重
- **自适应机制**：根据历史表现自动调整偏差强度

### 2. 视觉厌恶检测
- **空间范围检测**：检测主车车头方向特定角度范围内（默认±30°）的威胁物体
- **距离感知**：在指定检测距离内（默认50米）识别潜在威胁
- **增强因子**：基于检测到的威胁应用视觉厌恶增强因子

### 3. 自适应偏差调整
- **历史学习**：基于奖励历史和TTA历史动态调整偏差参数
- **适应性控制**：在设定的最小和最大因子范围内自动调节偏差强度
- **平衡机制**：避免过度偏差影响学习效果

## 主要特性

### 工作模式
- **PPO专用**：模块仅在PPO模式下生效，不影响其他训练模式
- **环境无关**：独立于gym环境，直接在MetaDrive环境中工作
- **可选集成**：支持通过配置参数灵活开启或关闭

### 数据记录
- **历史追踪**：记录偏差历史、奖励历史、TTA历史用于分析
- **检测记录**：详细记录威胁检测信息和视觉厌恶计算过程
- **统计信息**：提供完整的模块运行统计数据

### 可视化支持
- **图表生成**：自动生成偏差分析图表
- **检测分析**：可视化威胁检测和视觉厌恶效果
- **历史趋势**：展示偏差随时间的变化趋势

## 技术实现

### 核心算法

#### 1. inverse_tta计算
```python
# 基于视觉威胁检测的手动计算
if threat_detected and min_threat_distance < float('inf'):
    if agent_speed > 0.1:
        # 基础计算
        basic_inverse_tta = agent_speed / min_threat_distance
        
        # 视觉厌恶增强
        distance_factor = max_detection_distance / min_threat_distance
        visual_aversion_factor = 1.0 + (distance_factor - 1.0) * visual_aversion_strength
        
        # 最终结果
        inverse_tta = basic_inverse_tta * visual_aversion_factor
```

#### 2. 奖励偏差应用
```python
if inverse_tta > tta_threshold:
    # 计算偏差量
    bias_factor = inverse_tta_coef * inverse_tta
    
    # 应用自适应因子
    if adaptive_bias:
        bias_factor *= adaptive_factor
    
    # 调整奖励（风险厌恶 = 惩罚高风险行为）
    adjusted_reward = original_reward - bias_factor
```

#### 3. 自适应调整
```python
# 基于TTA历史调整
if avg_tta > tta_threshold * 1.5:
    adaptive_factor = min(max_adaptive_factor, adaptive_factor + adaptation_rate)
elif avg_tta < tta_threshold * 0.5:
    adaptive_factor = max(min_adaptive_factor, adaptive_factor - adaptation_rate)
```

### 配置参数

#### 基础参数
- `inverse_tta_coef`：偏差强度系数（默认1.0）
- `tta_threshold`：TTA阈值，超过此值时应用偏差（默认1.0）
- `adaptive_bias`：是否启用自适应偏差（默认True）

#### 视觉检测参数
- `visual_detection_distance`：视觉检测距离，米（默认50.0）
- `visual_detection_angle`：视觉检测角度，度（默认30.0）
- `visual_aversion_strength`：视觉厌恶增强强度（默认0.5）

#### 自适应参数
- `adaptation_rate`：自适应调整速率（默认0.01）
- `min_adaptive_factor`：最小自适应因子（默认0.5）
- `max_adaptive_factor`：最大自适应因子（默认2.0）

## 使用方法

### 1. 模块初始化
```python
# 创建配置
bias_config = {
    'inverse_tta_coef': 1.0,
    'tta_threshold': 1.0,
    'adaptive_bias': True,
    'visual_detection_distance': 50.0,
    'visual_detection_angle': 30.0,
    'visual_aversion_strength': 0.5,
    'verbose': True
}

# 初始化模块
cognitive_bias_module = CognitiveBiasModule(bias_config)
```

### 2. 环境集成
```python
# 附加到环境
success = cognitive_bias_module.attach_to_env(env)

# 处理奖励
adjusted_reward, bias_info = cognitive_bias_module.process_reward(
    original_reward=reward,
    env=env,
    info=info,
    is_ppo_mode=True
)
```

### 3. 状态管理
```python
# 重置状态
cognitive_bias_module.reset()

# 获取统计信息
stats = cognitive_bias_module.get_statistics()

# 生成可视化
cognitive_bias_module.generate_visualization(env, save_dir)
```

## 输出说明

### 统计信息
- `total_steps`：总处理步数
- `active_steps`：偏差激活步数
- `activation_rate`：激活率
- `total_bias`：累积偏差量
- `average_bias`：平均偏差量
- `adaptive_factor`：当前自适应因子

### 偏差信息
- `original_reward`：原始奖励
- `bias_applied`：应用的偏差量
- `inverse_tta`：当前inverse_tta值
- `adaptive_factor`：当前自适应因子
- `bias_active`：偏差是否激活

### 可视化图表
- **奖励对比图**：原始奖励vs调整后奖励
- **检测分析图**：威胁检测统计
- **视觉厌恶详情**：视觉厌恶增强效果分析
